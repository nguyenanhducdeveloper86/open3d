# Implementation plan

## Phase 0 — public foundation (complete)

Publish the contract/schema surface, dependency-light CLI, immutable artifact store, deterministic GLB fixture, QA report, checkpoint/rollback, MCP experiment, license/security docs, contribution templates, and CI.

## Phase 1 — worker boundary

Add a versioned job runner with parent watchdog, canonical path/symlink checks, read-only input mounts, output quotas, and a tested Blender worker. Keep community skills disabled until the host sandbox is real.

## Phase 2 — evidence and engines

Add a small GLB viewer with explicit disposal, semantic selection, locked camera renders, and a licensed Unity batch validator. Engine reports remain evidence and never replace core QA.

## Phase 3 — adapters

Add provider manifests, explicit upload consent, digest/license checks, and one optional local or remote adapter. Normalize all candidates into the existing contract and run the same QA.

## Phase 4 — alpha release

Run golden corpus, security/path tests, clean-room onboarding, dependency/license inventory, SBOM/provenance, signed packages, and maintainer review. Do not call the release production-ready while any required gate is only a stub.
