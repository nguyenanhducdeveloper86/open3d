# Governance

Open3D Artist uses lazy consensus while the project is small: a maintainer may merge a reviewed, green change when no substantive objection remains.

Schema, protocol, security, release, and provider-license changes need two maintainer reviews and an ADR or compliance note. Documentation and ordinary code need one maintainer review. No contributor can approve their own security-sensitive change.

Maintainers are trusted contributors who consistently review, release, and support the project. Existing maintainers may add or remove maintainers by consensus; disputes are resolved by the project owner until a larger maintainer group is established.

The project uses DCO 1.1 rather than a CLA. Contributions remain under the repository license unless a separate written agreement says otherwise.
