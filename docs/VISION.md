# Vision

Make 3D asset creation inspectable and reversible for humans and agents.

Open3D Artist treats the asset contract, artifact digest, semantic part identity, QA evidence, and checkpoint history as first-class data. Generative providers can suggest candidates, but deterministic validation and explicit user consent remain the authority.

The v0.1 product is a narrow offline prop workflow. Characters, rigs, worlds, learned retopology, marketplace distribution, and autonomous “looks good” approval stay out of the release blocker until the core contracts prove durable.
